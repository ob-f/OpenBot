로봇 앱은 로봇 위에 올려진 휴대폰이나 컴퓨터에서 실행됩니다. 로봇 바디와 통신하고, 컨트롤러로 영상을 스트리밍하며, 주행 정책을 실행합니다.

- [Android](android/README.ko-KR.md): 최신 릴리스에서 APK를 설치하거나 Android Studio에서 빌드하세요(`robot/android`를 엽니다).
- [iOS](ios/README.ko-KR.md) (베타): Xcode로 빌드하세요. 아직 App Store에는 없습니다.
- [Linux](linux/README.ko-KR.md): 카메라가 달린 Linux 컴퓨터용 Python 버전입니다.
