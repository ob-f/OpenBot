La aplicación del robot se ejecuta en el teléfono u ordenador que va sobre el robot. Se comunica con el cuerpo del robot, transmite vídeo a un controlador y ejecuta las políticas de conducción.

- [Android](android/README.es-ES.md): instala el APK de la última versión publicada, o compílalo en Android Studio (abre `robot/android`).
- [iOS](ios/README.es-ES.md) (beta): compílala con Xcode; todavía no está en la App Store.
- [Linux](linux/README.es-ES.md): una versión en Python para un ordenador Linux con cámara.
