机器人应用运行在安装于机器人上的手机或电脑上。它与机器人车身通信，向控制器传输视频，并运行驾驶策略。

- [Android](android/README.zh-CN.md): 从最新发布版本安装 APK，或在 Android Studio 中构建（打开 `robot/android`）。
- [iOS](ios/README.zh-CN.md) （测试版）：使用 Xcode 构建；尚未在 App Store 上架。
- [Linux](linux/README.zh-CN.md): 适用于带摄像头的 Linux 电脑的 Python 版本。
