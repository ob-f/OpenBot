Die Roboter-App läuft auf dem Smartphone oder Computer, der auf dem Roboter sitzt. Sie kommuniziert mit dem Roboterkörper, streamt Video an einen Controller und führt die Fahrstrategien aus.

- [Android](android/README.de-DE.md): Installieren Sie die APK aus der neuesten Veröffentlichung oder bauen Sie sie in Android Studio (öffnen Sie `robot/android`).
- [iOS](ios/README.de-DE.md) (Beta): mit Xcode bauen; sie ist noch nicht im App Store.
- [Linux](linux/README.de-DE.md): eine Python-Version für einen Linux-Computer mit Kamera.
