L'application robot tourne sur le téléphone ou l'ordinateur posé sur le robot. Elle communique avec le corps du robot, diffuse la vidéo vers un contrôleur et exécute les politiques de conduite.

- [Android](android/README.fr-FR.md): installez l'APK de la dernière version publiée, ou compilez-la dans Android Studio (ouvrez `robot/android`).
- [iOS](ios/README.fr-FR.md) (bêta) : compilez-la avec Xcode ; elle n'est pas encore sur l'App Store.
- [Linux](linux/README.fr-FR.md): une version Python pour un ordinateur Linux avec une caméra.
