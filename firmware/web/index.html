Serial Monitorat startup

Sets the battery, the parts and phone or no phone mode on a robot that already has this firmware, without flashing.

  1. Get the firmware from the firmware folder and open openbot/openbot.ino.
  2. Download the settings file and put it next to openbot.ino.
  3. Select your board in the Arduino IDE and upload.

Connecting your robot by USB

  1. Use a USB data cable. Many cables only charge. If no port shows up, try another cable.
  2. Close other programs that use the port, like the Arduino IDE's Serial Monitor.
  3. Click Flash firmware and choose the board's port. It's called something like COM3 on Windows, cu.usbserial-… or cu.wchusbserial… on a Mac, and ttyUSB0 on Linux.

No port shows up?

Your computer may need a driver for the board's USB chip. The chip's name is printed on it, next to the USB socket.

USB chipFound onDriver
CH340, CH341Most Nano clones, many ESP32 boardsWindows · macOS
CP2102, CP2104Many ESP32 boardsSilicon Labs
FTDIOriginal Arduino NanoFTDI

On Linux no driver is needed, but your user must be allowed to use serial ports: run sudo usermod -aG dialout $USER, then log out and in again.

It doesn't connect?

ESP32: hold the board's BOOT button while flashing starts, and let go once it writes.

Nano: the page tries the new and the old bootloader by itself. If both fail, press the reset button just after clicking Flash firmware.

Flashing uses Web Serial and works in Chrome or Edge on a computer. The settings file works with any browser.
