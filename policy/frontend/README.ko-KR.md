이 프로젝트는 [Create React App](https://github.com/facebook/create-react-app)으로 만들어졌습니다.

## 사용 가능한 스크립트

프로젝트 디렉터리에서 다음을 실행할 수 있습니다.

### `yarn start`

개발 모드로 앱을 실행합니다.\
브라우저에서 [http://localhost:3000](http://localhost:3000)을 열어 확인하세요.

코드를 수정하면 페이지가 다시 로드됩니다.\
린트 오류도 콘솔에 표시됩니다.

### `yarn test`

대화형 감시 모드로 테스트 러너를 실행합니다.\
자세한 내용은 [테스트 실행](https://facebook.github.io/create-react-app/docs/running-tests) 섹션을 참고하세요.

### `yarn build`

프로덕션용 앱을 `build` 폴더에 빌드합니다.\
React를 프로덕션 모드로 올바르게 번들링하고 최상의 성능을 위해 빌드를 최적화합니다.

빌드는 압축되며 파일 이름에 해시가 포함됩니다.\
앱을 배포할 준비가 되었습니다!

자세한 내용은 [배포](https://facebook.github.io/create-react-app/docs/deployment) 섹션을 참고하세요.
